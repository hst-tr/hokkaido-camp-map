# 北海道キャンプ場 MAP

北海道のキャンプ場を、エリア・キャンプスタイル・ロケーション・設備などの条件から検索できるデモサイトです。

キャンプ場検索ポータルサイトの構築を想定し、検索・地図表示・詳細ページ・レスポンシブ対応・動画を使用したビジュアル表現など、Webサイト制作に必要となる基本的な機能を実装しています。

## Overview

北海道のキャンプ場を探すユーザーを想定した検索ポータルサイトのデモです。

トップページでは北海道のキャンプ風景を使用した動画を背景として表示し、キャンプ場検索ページでは検索条件に応じた施設一覧と地図を同時に確認できます。

各キャンプ場には詳細ページを用意し、所在地・キャンプスタイル・周辺環境・設備などの情報を確認できる構成としています。

## Features

### キャンプ場検索

以下の条件からキャンプ場を絞り込めます。

- キーワード
- エリア
- キャンプスタイル
  - オートキャンプ
  - フリーサイト
  - コテージ
  - グランピング
- ロケーション
  - 海
  - 湖
  - 川
  - 林間
  - 高原
- 設備
  - 温泉
  - シャワー
  - AC電源
  - 水洗トイレ
  - ゴミ捨て場
  - ペット
  - Wi-Fi

### 地図表示

検索結果に含まれるキャンプ場を地図上に表示します。

一覧からキャンプ場を選択すると、対応する地図上の位置を確認できます。

### キャンプ場詳細ページ

キャンプ場ごとに詳細ページを用意しています。

- キャンプ場名
- 所在地
- エリア
- キャンプスタイル
- ロケーション
- 設備
- 料金
- 公式サイト
- データ出典

### レスポンシブ対応

PC・タブレット・スマートフォンの画面サイズに対応しています。

検索ページでは、PCではキャンプ場一覧と地図を横並びで表示し、スマートフォンでは地図を上部に配置してから検索結果を表示する構成としています。

### トップページ動画

トップページでは `top.mp4` を背景動画として使用しています。

- 自動再生
- ミュート
- ループ再生
- レスポンシブ表示
- `object-cover` による画面サイズへの対応

### オープニング動画

サイト初回アクセス時には `op.mp4` によるオープニングアニメーションを表示します。

動画終了後はフェードアウトして本編へ移行します。

また、`sessionStorage` を使用して、同一セッション中はオープニング動画を再表示しない仕様としています。
